# Kernel & Press

Marketing website for **Kernel & Press** (Kernel and Press Pvt Ltd), an Indian cold-pressed culinary oils brand in Sangareddy, Telangana.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

| Command | What it does |
| --- | --- |
| `npm run dev` | Development server (Turbopack) |
| `npm run build` | Production build |
| `npm start` | Serve the production build |
| `npm run lint` | ESLint |

## Stack

Next.js (App Router), TypeScript, Tailwind CSS.

Brand mark lives in `public/logo.jpg` (full lockup) and `public/mark.png` (press emblem for the header).

## Pages

- `/` — motto, value props, process preview, example oils
- `/products` — placeholder oil range (update when SKUs are final)
- `/process` — seed → expeller → double filter → packing
- `/about` — brand story
- `/contact` — address, phone, email, mailto form
